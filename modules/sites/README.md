# `sites` — static sites (W18)

Agents publish small static sites (HTML, CSS, JavaScript, images) on the server's separate sites origin, never on
the app origin. The owner manages them on the Sites screen.

| Piece      | Here                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| tables     | `sites_site`(id, slug, agent_id, title, public, bytes, files, created_at, updated_at, expires_at), `sites_file`(site_id, path, sha256, mime, size)                                                                                                                                                                                                                                                                                                                            |
| files      | bytes in the module's own store `<dataDir>/store/<sha256>` (not the shared BlobStore, which has no delete), deleted as soon as no site row points at them (unpublish, replace, expiry, owner remove; orphans from a crash are dropped at boot); copied onto the sites origin through `ModuleHost.sitesOrigin` at `<sites origin>/sites/<slug>/<path>`; every boot puts each live site back (so content types survive a restart) after dropping what expired                   |
| address    | slug = readable title part + 10 random characters (unguessable); the URL points at the site's `index.html`                                                                                                                                                                                                                                                                                                                                                                    |
| isolation  | the core sites listener sends `CSP: sandbox allow-scripts` + `nosniff` on every response: a site's script runs on an opaque origin, reads no cookie, and the app refuses its `/api` writes and `/ws` (403) and answers its reads 401 (no cookie is sent)                                                                                                                                                                                                                      |
| tools      | `sites_publish` (2; a call refused by the quotas is 0 so the owner is never asked about it), `sites_list` (0, own sites), `sites_renew` (1, own site), `sites_unpublish` (1, own site)                                                                                                                                                                                                                                                                                        |
| quotas     | 20 files per site (the 21st is refused), 512 KB per file, 1 MB per site (one tool call carries the whole site and the server takes at most 1 MB per request), 10 live sites and 10 MB per agent, 30 publishes (new or replacing) per agent per hour (in memory); every publish, unpublish, removal and expiry runs one at a time, so concurrent publishes cannot pass the quotas together; paths are plain relative segments with an allowed extension; `index.html` required |
| expiry     | default 7 days, at most 30; renew extends from now; an expiry job (every 60 s, and at boot) removes the files and the rows                                                                                                                                                                                                                                                                                                                                                    |
| public     | the owner may set a tunnel address (`PUT /settings`); a site marked public then also shows `<tunnel>/sites/<slug>/index.html`. The tunnel itself is the owner's (W20 guide)                                                                                                                                                                                                                                                                                                   |
| redaction  | text files (html, css, js, json, txt, md, csv, svg, xml) pass `ModuleHost.redact` before they are published                                                                                                                                                                                                                                                                                                                                                                   |
| owner REST | `GET /api/m/sites/sites`, `POST /sites/:id/renew`, `POST /sites/:id/public`, `DELETE /sites/:id`, `PUT /settings` — owner session only                                                                                                                                                                                                                                                                                                                                        |
| web        | Sites screen `#/sites` (nav item): who published each site, files, size, expiry, Open (new tab on the sites origin, `safeHref`), Keep 7 more days, Make public/private, Remove, tunnel address                                                                                                                                                                                                                                                                                |
| locale     | `locales/en.json`, `locales/fil.json` (namespace `sites`)                                                                                                                                                                                                                                                                                                                                                                                                                     |

Known limits: the sites listener cannot tell tunnel traffic from LAN traffic, so if the owner's tunnel forwards the
whole sites address, a private site is reachable from outside by anyone who knows its (unguessable) address.

Proof:

- `vitest run modules/sites`: publish a 3-file site and open its URL on the sites origin; CSP + nosniff on every
  response (404s and traversal attempts included); 403 for a write and a `/ws` upgrade from the sites origin even
  with the owner's cookie, 401 without one; 21st file, bad paths, oversize file and a missing `index.html` refused
  without an approval; tier 2 waits for the owner for a guarded agent; another agent cannot replace, renew or remove
  a site; replacing keeps the address; a vault secret is redacted from a published page; owner REST (member 403,
  tunnel address, public toggle, renew, remove); the expiry job removes an expired site and keeps a renewed one; unpublish, replace and expiry free the stored bytes (a file another site uses stays) and nothing lands in the BlobStore; 6 concurrent publishes at 9 live sites yield exactly one; the 31st publish in an hour is refused without an approval; a
  restart serves a live site again with its content type and drops the one that expired meanwhile.
- `pnpm --filter @pasabot/web exec vite build && pnpm --filter @pasabot/mod-sites test:e2e` (1440 and 390 px): a
  standard agent publishes a 3-file site after the owner approves the tier 2 card; the 21st file is refused; the owner
  opens Sites from the nav, opens the site in a new tab (CSS applied; every sites response sandboxed; the site's script
  reads no cookie, its `/api` calls and `/ws` fail), renews it, sets a tunnel address, makes it public, sees FIL, and
  removes it (the URL then answers 404); no side scroll, 44 px buttons on a phone.
